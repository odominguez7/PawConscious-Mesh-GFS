How it works

One URL in. A signed evidence bundle out.

01 · Submit
Paste a product page URL.
Any pet supplement PDP. The mesh fetches it via Firecrawl and parses every health claim on the label.
02 · Mesh
Five ADK agents fan out via A2A.
Claim extractor · evidence grader (PubMed via BioMCP) · vet rubric · FTC §255.3 compliance · adversarial auditor. All on Gemini 2.5 Pro.
03 · Sign
PCEC v0.1 bundle, Ed25519 signed, chain-anchored.
Every signing event appends to a Firestore transparency log. The chain head is public. Any A2A agent can fetch and verify.
The artifact

Not a badge. A signed document the agentic shelf can verify.

Every claim on the label is mapped to citations, scored by a rubric, checked against the FTC endorsement guide, and cryptographically signed. The bundle is machine-readable JSON-LD over A2A v0.3, with a SHA256 chain anchor anyone can audit.

Amazon Rufus, Chewy's recommender, or any A2A v0.3 agent can fetch the bundle, verify the signature, and surface the product as evidence-backed.

Why PawConscious

Four reasons this is the layer AI agents will call.

01
We authored an open spec.
PCEC v0.1 is MIT-licensed. Donation path to the Linux Foundation, the same route Adobe used for C2PA.
02
We run a structured rubric.
A five-criterion vet-style rubric grades every claim against PubMed (via BioMCP) and the FTC §255.3 substantiation rule. Roadmap: stipend-funded panel from accredited veterinary nutrition programs.
03
We ship the signed bundle.
Ed25519 signature, Firestore transparency log, public A2A v0.3 agent card at /.well-known/agent-card.json. Any A2A-compatible agent can fetch and verify in one HTTP request.
