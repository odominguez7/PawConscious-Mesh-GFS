Architecture · Google Cloud native

      
Seven specialized agents · A2A · Vertex AI Search · Ed25519 · Firestore chain · Adversarial Second Opinion.

      
Hover any agent to see its Google tool, model, temperature, and typical latency. Every component below maps to live production code in the open-source repo.

7 Agents · 3 StagesShape

        
Stage 1 (reasoning mesh, 5 agents): claim-extractor first, then evidence-grader · vet-rubric · compliance fan out per claim via asyncio.gather, then auditor merges. Stage 2: Ed25519 sign + chain anchor. Stage 3 (post-sign, 2 agents): cert-composer + adversarial second-opinion run in parallel.

      

      

        
ADK 2.0Orchestration

        
Four of seven agents wrap as google.adk.agents.LlmAgent (claim-extractor, evidence-grader, compliance, auditor); the orchestrator fans them out via asyncio.gather. The other 3 call google.genai SDK direct for v0.1 deterministic latency. ADK ParallelAgent + SequentialAgent wrappers are documented as the Phase 4 Vertex AI Agent Engine deployment surface.

      

      

        
Gemini 2.5Reasoning

        
2.5 Pro for claim extraction, evidence grading, vet rubric, compliance mapping, cert composer, and adversarial Second Opinion (6 agents). 2.5 Flash for the deterministic auditor (1 agent). Most calls use temperature=0.0; Second Opinion uses 0.3 for adversarial breadth.

      

      

        
GroundingTruth

        
Vertex AI Search grounds the compliance agent against a public-redistributable regulator corpus (FTC 16 CFR §255 · AAFCO PF7 · NASC). Google Search grounding via google.genai powers the Second Opinion's 4 stress tests (court · regulator · consensus · public skepticism). Vet-panel is intentionally prompt-only. No licensed handbook ingest.

      

      

        
A2A v0.3Interop

        
Public agent card at /.well-known/agent-card.json. Async lifecycle: /tasks/send → poll /tasks/get. External ShopperAgent (separate Cloud Run service, MIT) consumes it end-to-end. No third-party integrations claimed.

      

      

        
MCP + CitationsEvidence

        
BioMCP (21 tools, MIT) → live PubMed / Europe PMC retrieval. Semantic Scholar Graph API batch enriches every paper with citation + influential-citation counts (public surface of AI2 Asta). The auditor verifies PMID format and direction match before signing.

      

      

        
Cloud Run + FirestoreRuntime

        
Mesh API + ShopperAgent are independent Cloud Run services (scale-to-zero, Artifact Registry images). Firestore holds the append-only transparency log: chain_anchor = sha256(bundle_hash + ":" + (prev_hash or "genesis")). Public head at /pcec/v0/chain/head.

Seven agents · three stages

        
Evidence, vet, compliance run in parallel. Auditor merges; adversarial second-opinion stress-tests.

        
See full 7-agent architecture →

      

      

        
03 · Sign

        
Ed25519 + chain anchor

        
Bundle signed against the mesh DID, appended to Firestore log. Any A2A v0.3 agent can verify.

→ { bundle_hash, signature,
    chain_anchor, output: {…} }
