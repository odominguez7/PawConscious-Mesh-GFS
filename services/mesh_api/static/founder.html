Why I built this

AI shopping agents will soon make millions of product recommendations, but most will simply repeat brand claims without checking the evidence.

So I built PCEC: an open protocol and agent mesh that verifies product claims, checks substantiation and FTC risk, scores the evidence, and cryptographically signs the verdict so any downstream agent can trust it.

See how the mesh is built, or watch it block a bad claim live.
